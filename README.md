# Abbas Taofeeq Portfolio

A modern personal portfolio for Abbas Taofeeq, positioned as a Frontend Engineer specializing in AI-powered, high-conversion web applications.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Update Personal Details

Most editable content lives in `lib/data.ts`:

- Projects
- Skills and expertise
- Experience

- Contact links
